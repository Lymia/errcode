# errcode

[![Latest Version](https://img.shields.io/crates/v/errcode.svg)](https://crates.io/crates/errcode)
![Requires rustc 1.89+](https://img.shields.io/badge/rustc-1.89+-red.svg)
[![Rust Documentation](https://img.shields.io/badge/api-rustdoc-blue.svg)](https://docs.rs/errcode)

errcode is a compact error type suitable for use in both libraries and binaries. It stores compact error codes instead of the underlying object, allowing the error to be programmatically examined at far less memory and runtime cost.

This is an experimental crate and is not yet ready for production.
